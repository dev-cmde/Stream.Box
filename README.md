# ![](https://dev.cmde.ru/streambox/24.png) Stream.Box

### Программа для стримеров, объединяющая несколько внешних сервисов для получения событий и использования их в Streamer.bot


</div>

---

## ✨ Возможности
| Функция | Описание |
|---------|----------|
| 💰 **Донаты** | Получение уведомлений. Поддержка DonationAlerts, DonatePay, DonateStream, Trula, Donatty |
| ⏱️ **Донатный таймер** | Автоматическое добавление времени за донаты |
| 💬 **VK Видео Live и Twitch** | **Мультичат** для стриминговых платформ и получение **наград за баллы** канала |
| 🎵 **Яндекс Станция** | Получение информации текущего трека для использования в OBS и чат-боте |
| 🔗 **Streamer.bot** | Интеграция с Streamer.bot для передачи событий |
| 🔄 **Автообновление** | Автоматическая установка новых версий |
