# ![](https://dev.cmde.ru/streambox/24.png) Stream.Box

### Программа для стримеров, объединяющая несколько внешних сервисов для получения событий и использования их в Streamer.bot

</div>

---

## ✨ Возможности
| Функция | Описание |
|---------|----------|
| 💰 **Донаты** | Получение уведомлений. Поддержка DonationAlerts, DonatePay, DonateStream, Trula, Donatty. Отправка в Streamer.bot |
| ⏱️ **Донатный таймер** | Автоматическое добавление времени за донаты. Корректировка времени, пауза, настройка стоимости. Виджет для OBS: `https://streambox.cmde.ru/timer.html` |
| 💬 **Мультичат** | Оверлей объединенного чата для **VK Видео Live** и **Twitch** со смайлами и цветами ников. Виджет для OBS: `https://streambox.cmde.ru/chat.html` |
| 🎵 **Яндекс Станция** | Получение информации текущего трека для использования в оверлее и чат-боте. Виджет для OBS |
| 🔗 **Streamer.bot** | Централизованная [интеграция со Streamer.Bot](https://github.com/dev-cmde/Stream.Box/wiki/Streamer.Bot:-установка,-триггеры-и-аргументы) для передачи событий, кастомные триггеры |
| 🔄 **Обновления** | Автоматическая установка новых версий |

## ✨ Инструкции / Ответы на вопросы
- Программа не требует установки, скачайте файл в любое удобное место. Обновления происходят автоматически, можно выключить в настройках.
- Авторизация на VK и Twitch реализована через официальные API платформ и не требует ввода логина и пароля. Ваши данные сохраняются в файле настроек на вашем ПК.
- Youtube не добавлен по религиозным убеждениям XD. Другие площадки добавлю по мере необходимости (пока не в приоритете).
- Донатные сервисы подключаются через токены. Но у Donatty из-за их протокола нужно ввести всю ссылку их виджета.
- [Интеграция со Streamer.Bot](https://github.com/dev-cmde/Stream.Box/wiki/Streamer.Bot:-установка,-триггеры-и-аргументы)
