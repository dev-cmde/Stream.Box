# Stream.Box
Программа для стримеров, объединяющая несколько сервисов. Донатный таймер, мультичат, интеграция с Яндекс Станцией.\
В первую очередь создавалась для централизованного использования событий в Streamer.bot.

---

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 💰 **Донаты** | Поддержка DonationAlerts, DonatePay, DonateStream, Trula, Donatty |
| 🔗 **Streamer.bot** | Интеграция с Streamer.bot для передачи событий |
| 💬 **Мультичат** | Чат из VK Video Live и Twitch в одном окне |
| ⏱️ **Донатный таймер** | Автоматическое добавление времени за донаты |
| 🎵 **Яндекс Станция** | Получение информации текущего трека для использования в OBS и чат-боте |
| 🔄 **Автообновление** | Автоматическая установка новых версий |

## ✨ Инструкции и документация

Пока нет. Можно задать вопросы, потом из ответов и соберём инструкции.\
Это первый релиз, поэтому важно отследить проблемы - если не запускается, если крашится, если не подключается и т.д. Базовые косяки.

Под капотом спрятан мультичат Twitch + VK Видео Live - со значками, цветами ников и смайлами.\
Также получаем разные события VK Видео Live и Boosty, но нужно сильно тестировать (у них там напутано). Подписки, награды за баллы канала. В планах доделать нормально.
