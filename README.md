# ![](https://dev.cmde.ru/streambox/24.png) Stream.Box

### Миссия Stream.Box: централизованное получение и обработка информации от внешних сервисов. Возможность использовать как автономно, так и для расширения возможностей Streamer.Bot

</div>

---

## ✨ Возможности
| Функция | Описание |
|---------|----------|
| 💰 **Донаты** | Получение уведомлений. Поддержка DonationAlerts, DonatePay, DonateStream, Trula, Donatty и MemeAlerts. Отправка в Streamer.Bot |
| ⏱️ **Донат-таймер** | Автоматическое добавление времени за донаты. Корректировка времени, пауза, настройка стоимости. Виджет для OBS: `https://streambox.cmde.ru/timer.html` |
| 🔔 **Уведомления** | Отправка уведомлений в Discord и Telegram. Настройка кнопок, картинок. |
| 💬 **Мультичат** | Оверлей объединенного чата для **VK Видео Live** и **Twitch** со смайлами и цветами ников. Виджет для OBS: `https://streambox.cmde.ru/chat.html` |
| 📢 **Озвучка** | Озвучка донатов, сообщений, интеграция со Streamer.Bot. 5 голосов, шаблоны текста озвучки, чёрный список, скип озвучки, громкость и скорость голоса. |
| 🎵 **Сейчас играет** | Медиа-виджет. Берёт информацию из: Приложения Яндекс музыка. GoogleChrome/Opera (ВК музыка, Яндекс Музыка, YouTube). Spotify и прочее - нужно тестировать. Виджет для OBS: `https://streambox.cmde.ru/player.html`  |
| 🎵 **Яндекс Станция** | Получение информации текущего трека для использования в виджете и чат-боте. |
| 🔗 **Streamer.Bot** | [Интеграция со Streamer.Bot](https://github.com/dev-cmde/Stream.Box/wiki/Streamer.Bot:-установка,-триггеры-и-аргументы). Отправка событий в Streamer.Bot и отправка из Streamer.Bot текстов на озвучку. |
| 🔄 **Обновления** | Проверка новых версий |

## 💎 Premium

**Доступ на 30 дней бесплатно** для всех, далее — при активной подписке на [Boosty](https://boosty.to/comrad_e).

### Что доступно в обычной версии?

Почти всё!

- **Уведомления о старте стрима** — отправка в Discord и Telegram с любой картинкой (Twitch-превью, своя)
- **Озвучка** — для донатов и сообщений чата
- **Мульти-чат** — приём сообщений с Twitch и VK, виджет для OBS
- **Донаты** — приём с DonationAlerts, Donatty, DonatePay, DonateStream, Trula, MemeAlerts. Отображение в ленте событий
- **Виджет «Сейчас играет»** — все источники Windows (Яндекс Музыка, Spotify, Telegram и др.)
- **Интеграция со Streamer.Bot** (двусторонняя) — отправка событий в Streamer.Bot и отправка из Streamer.Bot текстов на озвучку

### Что под Premium?

- **Донат-таймер** — таймер с начислением времени за донаты. Виджет для OBS + управление в окне
- **AI-генерация картинок** — генерация уникальной обложки для уведомления по названию стрима
- **Яндекс Станция** — трансляция треков с Яндекс Станции в виджет «Сейчас играет»

**📢 Premium является просто формой поддержки разработчика и открывает только некоторые специфичные функции.**
