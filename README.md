# ![](https://dev.cmde.ru/streambox/24.png) Stream.Box

### Программа для стримеров, объединяющая несколько внешних сервисов для получения событий и использования их в Streamer.bot


</div>

---

## ✨ Возможности
| Функция | Описание |
|---------|----------|
| 💰 **Донаты** | Получение уведомлений. Поддержка DonationAlerts, DonatePay, DonateStream, Trula, Donatty. Отправка в Streamer.bot |
| ⏱️ **Донатный таймер** | Автоматическое добавление времени за донаты. Корректировка времени, пауза, настройка стоимости. HTML-виджет |
| 💬 **Мультичат** | Оверлей объединенного чата для **VK Видео Live** и **Twitch** со смайлами и цветами ников. HTML-виджет |
| 🎵 **Яндекс Станция** | Получение информации текущего трека для использования в оверлее и чат-боте. HTML-виджет плеера |
| 🔗 **Streamer.bot** | Централизованная интеграция со Streamer.bot для передачи событий, кастомные триггеры |
| 🔄 **Обновления** | Автоматическая установка новых версий |
